# Binary Number Increment using Turing Machine

## Introduction
This project demonstrates the implementation of a Binary Number Increment operation using a Turing Machine. The machine takes a binary number as input and increments it by 1 using tape operations and transition rules.

## Problem Statement
To design and simulate a deterministic single-tape Turing Machine that increments a given binary number by 1 and displays the execution step by step.

## Objectives
- To design a Turing Machine for binary number increment.
- To understand binary addition and carry propagation.
- To visualize tape movement and state transitions.
- To simulate binary increment step by step.
- To analyse the time and space complexity.

## Working of the Project

The Turing Machine uses three states:

- **q0:** Scans the binary input from left to right.
- **q1:** Performs carry propagation from right to left.
- **qf:** Final halting state.

### Example

Input: `1011`

Operation: `1011 + 1`

Output: `1100`

## Features
- Accepts binary number as input.
- Performs binary increment by 1.
- Displays Turing Machine tape.
- Shows head position and current state.
- Demonstrates step-by-step execution.
- Displays transition rules.
- Handles numbers containing only 1s.
